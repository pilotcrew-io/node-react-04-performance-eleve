# Sources officielles et lecture utile

Références consultées pour la rédaction le **12 octobre 2026**. Les tutoriels sont des exercices originaux ; la documentation décrit les outils, pas une solution complète au magasin fictif. Vérifier les versions exactes dans vos manifests et lockfiles.

- [React — useEffect](https://react.dev/reference/react/useEffect) — Dépendances, nettoyage des effets et réponses réseau tardives.
- [MDN — AbortController](https://developer.mozilla.org/en-US/docs/Web/API/AbortController) — Transmettre un signal d’annulation aux requêtes et nettoyer les synchronisations.
- [web.dev — Web Vitals](https://web.dev/articles/vitals) — LCP, INP et CLS ; distinguer observation en laboratoire et expérience terrain.
- [web.dev — Largest Contentful Paint](https://web.dev/articles/lcp) — Interpréter le chargement du contenu principal et le seuil indicatif de 2,5 secondes.
- [web.dev — Interaction to Next Paint](https://web.dev/articles/inp) — Observer la réactivité aux interactions ; seuil indicatif de 200 millisecondes.
- [web.dev — Cumulative Layout Shift](https://web.dev/articles/cls) — Mesurer les déplacements visuels inattendus ; seuil indicatif de 0,1.
- [Chrome — Analyze runtime performance](https://developer.chrome.com/docs/devtools/performance) — Enregistrer un scénario et rechercher son coût dans une trace Performance.
- [Vite — Preview Options](https://vite.dev/config/preview-options.html) — Servir localement le build pour une comparaison maîtrisée ; ce serveur de prévisualisation n’est pas une plateforme de production.
